# CSI1430-Tetris
Final Project for Spring CSI1430, Tetris *plays type-a*

## Build Instructions
Requires vcpkg to install the files used by SDL Plotter.\
Follow [these](https://learn.microsoft.com/en-us/vcpkg/get_started/get-started-msbuild?pivots=shell-powershell) instructions to install it.

1. Open Tetris_VS.sln
2. Build Release or Debug.
3. Run using the Windows Debugger (sound and text don't work otherwise; I didn't know any better).

## Controls
### Menu
Hover over a difficulty and press any keyboard key to select.
Press Escape at any time to exit.

### Game
Use mouse to move piece left and right
Use LEFT and RIGHT arrow keys to rotate
Use DOWN to drop the piece to the bottom instantly.
